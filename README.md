## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Community & Security

Flowstride enforces a unified Code of Conduct and Security Policy across all our repositories.

- **Code of Conduct:** Please read our [Code of Conduct](https://github.com/heroamogs/flowstride-os/blob/prod/CODE_OF_CONDUCT.md) before participating in our community.
- **Security:** If you find a vulnerability in this website or the core framework, please follow our [Responsible Disclosure Policy](https://github.com/heroamogs/flowstride-os/blob/prod/SECURITY.md).
